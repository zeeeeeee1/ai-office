# もらったスキルの置き場所

ほかの人からもらったスキル（Claude Code のスキル）は、このフォルダに入れます。

```
skills/
└── <スキル名>/
    └── SKILL.md
```

- **ここに入れたものは git に入りません**（この README と `.gitignore` 以外は無視されます）。もらったスキルを誤って公開しないためです。
- AI社員の設定（初期メンバーの JSON か画面の「使うスキル」）にスキル名を書くと、その社員が使えるようになります。
- 同じ名前のスキルが作業ディレクトリの `skills/` や `.claude/skills/` にもあれば、そちらを先に使います。
- 別のフォルダに置きたいときは、作業ディレクトリの `config/ai_office.json` に `"external_skill_dirs": ["~/my-received-skills"]` のように書きます。
- いま何が見つかっているかは `python3 office.py skills` で確かめられます（📦 がもらったスキル）。
- 入れる前に、中身を読んで、知らない送信先へのアクセスや削除などの危ない操作が無いかを確かめてください。
